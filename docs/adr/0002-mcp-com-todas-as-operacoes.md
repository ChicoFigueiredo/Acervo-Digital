# MCP expõe todas as operações e é exceção à regra de não enviar o inventário à nuvem

O DAG oferece um servidor MCP por stdio (`dag mcp`) que repassa cada operação ao worker, mantendo o worker como único escritor do Catálogo. O MCP expõe todas as operações, inclusive instalar ou remover o serviço e disparar pedidos Polkit; a autorização administrativa continua sempre no diálogo do sistema, nunca no MCP. Como clientes MCP como o Claude processam as respostas na nuvem, a regra da spec v1.0 "nunca enviar inventário à nuvem na Fase A" passa a ter uma exceção: vale enviar caminhos e metadados ao cliente MCP que o próprio usuário configurou. Nenhuma outra via envia o inventário para fora da máquina. Decidido em 23/11/2026; rejeitamos HTTP local (porta e token a gerir) e o ocultamento de caminhos por padrão.
